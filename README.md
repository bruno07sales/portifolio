# Tentando mostrar meu trabalho ao mundo, um dev junior em construção

Este é o meu portfólio pessoal: um cantinho da internet onde organizo projetos, experiências e algumas provas de que os bugs também podem virar aprendizado (depois de algumas horas encarando o console).

## Sobre o portfólio

O site apresenta um pouco sobre mim, minhas principais tecnologias e projetos nas áreas de back-end, dados, automação, mobile e desenvolvimento web. Tudo foi construído com foco em uma navegação simples, visual responsivo e uma pitada saudável de personalidade.

## Por que está tudo em JavaScript por aqui?

Embora minha experiência não se limite ao JavaScript, as demonstrações publicadas neste portfólio foram adaptadas para essa linguagem por uma razão bem prática: o deploy no GitHub Pages. Assim, os projetos podem rodar diretamente no navegador, sem servidor, configuração de ambiente ou aquele clássico “na minha máquina funciona”.

Alguns projetos nasceram com outras tecnologias — como o sistema de otimização de rotas, originalmente desenvolvido em Python com OSMnx e NetworkX — e ganharam uma versão web em JavaScript para ficarem acessíveis a qualquer pessoa por meio de um link.

## Tecnologias deste portfólio

- HTML5 — porque toda grande aventura começa com uma `div`;
- CSS3 — responsável por convencer o HTML a sair bem na foto;
- JavaScript — adicionando interação e lembrando que `undefined` também é uma resposta;
- Git e GitHub — para versionar o código e, ocasionalmente, descobrir quem quebrou tudo (geralmente eu mesmo).

## Como executar

Não precisa instalar dependências, configurar banco de dados ou consultar os astros:

1. Clone este repositório;
2. Abra o arquivo `index.html` no navegador;
3. Pronto. Se algo quebrar, agora você já está vivendo a experiência completa de desenvolvimento.

Também é possível executar o projeto com uma extensão de servidor local, como o Live Server, para facilitar o desenvolvimento.
